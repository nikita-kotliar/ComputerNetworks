# Домашнє завдання до модуля 1: Основи комп'ютерних мереж
Змінив фактичні IP-адреси та MAC-адреси на «(сховано)»

## Завдання 1. Дослідження мережі

Команда:

```bash
ip a
```

Результат:

```
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN group default qlen 1000
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo
       valid_lft forever preferred_lft forever
    inet6 ::1/128 scope host proto kernel_lo
       valid_lft forever preferred_lft forever
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc mq state UP group default qlen 1000
    link/ether (сховано) brd ff:ff:ff:ff:ff:ff
    altname (сховано)
    inet (сховано)/20 brd (сховано) scope global eth0
       valid_lft forever preferred_lft forever
    inet6 fe80::215:5dff:fed8:9a7f/64 scope link proto kernel_ll
       valid_lft forever preferred_lft forever
3: docker0: <NO-CARRIER,BROADCAST,MULTICAST,UP> mtu 1500 qdisc noqueue state DOWN group default
    link/ether (сховано) brd ff:ff:ff:ff:ff:ff
    inet (сховано)/16 brd (сховано) scope global docker0
       valid_lft forever preferred_lft forever
```


| Параметр | Значення | Пояснення |
|---|---|---|
| Інтерфейс | `eth0` | Основний мережевий інтерфейс |
| Тип підключення | Ethernet (віртуальний) | Я працюю в WSL2 `eth0` - це віртуальний, а не фізична мережева карта чи Wi-Fi. |
| MAC-адреса | `(сховано)` | Фізична адреса інтерфейсу. Рівень - 2 (канальний). |
| IP-адреса | `(сховано)` | Логічна адреса вузла. Рівень - 3 (мережевий). Адреса приватна (діапазон `172.16.0.0 - 172.31.255.255`). |
| Маска | `/20` = `255.255.240.0` | яка частина є мережа а яка - хостом. Рівень - 3 (мережевий). |
| Gateway | `(сховано)` | Шлюз за замовчуванням, `default via` у результаті `ip r`. |
| Broadcast | `(сховано)` | бродкаст адреса мережі (всі біти хоста дорівнюють 1). |
| Hosts | `4094` | Адреса мережі `(сховано)`, діапазон `(сховано)`. |

як рахував: маска `/20` - `32 - 20 = 12` біт, тому `2^12 - 2 = 4096 - 2 = 4094` (мінус адреса мережі та broadcast).

## Завдання 2. Дослідження маршрутизації

Команда:

```bash
ip r
```

Результат:

```
default via (сховано) dev eth0 proto kernel onlink
(сховано)/16 dev docker0 proto kernel scope link src (сховано) linkdown
(сховано)/20 dev eth0 proto kernel scope link src (сховано)
```

**Протокол:** `kernel`.

маршрути створило ядро Linux коли налаштовуються інтерфейси, а не динамічний протокол маршрутизації і не DHCP. У WSL2 адресу та шлюз для `eth0` видає і налаштовує сама WSL

Пояснення рядків:

- `default via (сховано) dev eth0` - весь трафік йде через шлюз `(сховано)`
- `(сховано)/20 dev eth0` - локальна мережа є напряму через `eth0`
- `(сховано)/16 dev docker0` - мережа Docker, `linkdown`, бо інтерфейс неактивний

## Завдання 3. Знаходження публічної IP-адреси

Команда:

```bash
curl ifconfig.io
```

Результат:

```
185.143.144.160
```

**Порівняння адрес:**

| Тип | Адреса |
|---|---|
| Локальна (приватна) | `(сховано)` |
| Публічна | `185.143.144.160` |

**Вони різні.**

Локальна адреса `(сховано)` є до приватного діапазону `172.16.0.0/12`. Такі адреси не маршрутизуються в інтернеті, і ними можуть користуватися різні мережі одночасно. Публічна адреса `185.143.144.160` - це те, під чим мене бачать сайти в інтернеті; її надає провайдер.

Різниця виникає через Network Address Translation, пристрої живуть за роутером. є одна публічна адреса від провайдера, а всередині роздає приватні адреси. Коли я відправляю запит в інтернет, роутер підміняє мою приватну адресу на свою публічну
